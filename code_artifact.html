蘇澳七星嶺步道（七星山健康步道）

步道入口就在蘇澳冷泉公園／煙波大飯店旁，從南方澳騎車過來約 8 分鐘。沿途依高度設有「一星觀泉、二星觀澳、三星觀山、四星觀樹、五星觀港、六星觀海」觀景台。

時間控制小撇步（銜接 15:15 入住飯店）：

因為全長階梯較多，若想在 15:00～15:30 準時進煙波泡湯，建議散步至「一星觀泉」或「二星觀澳」俯瞰蘇澳市景後原路折返（來回約 45 分鐘）；若體力充沛想攻頂「六星觀海」，可微調至 15:40 再辦理入住。

七星嶺步道入口導航

內埤海灘（情人灣／內埤海水浴場）踏浪散步

從煙波飯店騎車過來約 10 分鐘。剛吃完豐盛的飯店早午餐，正好沿著優美的弧形海灣散步消化、拍美照、聽太平洋海浪拍打細砂礫石的聲音。如果走累了，岸邊也有一整排海景咖啡廳可以隨時坐下來喝杯冰飲。

安全提醒：內埤海灘屬於陡降型海溝地形，海浪暗流強勁，請在岸上散步觀海拍照即可，切勿下水游泳！

分享行程 & GitHub Pages 上傳教學

這份網頁已經打包為單一獨立的 index.html 檔案，只要 3 步驟就能免費發布到 GitHub 讓旅伴用手機瀏覽：

  1. 在 GitHub 建立一個公開的 Repository（例如命名為 suao-trip）。
  2. 將此程式碼儲存為 index.html 並上傳（Upload files）至該專案根目錄。
  3. 進入專案的 Settings ➔ Pages，在 Branch 選擇 main 並按 Save，約 1 分鐘後就會產生專屬網址（如 https://你的帳號.github.io/suao-trip/）！
